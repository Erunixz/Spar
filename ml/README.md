# ml

Training, evaluation and ONNX export for the in-browser models (Phase 4 onward).

- `notebooks/` Kaggle/Colab notebooks
- `src/` `train_*.py`, `export_onnx.py`
- `eval/` metrics and the CAT simulation
- `model_cards/` one card per published model

Datasets and checkpoints (`ml/data/`, `ml/checkpoints/`, `*.onnx`) are git-ignored.
